## 本周目标与最终架构

vue + vite + Hono + deepsseek api 前端面试小助手

1. 为什么 API Key 必须放后端
   防止apikey泄漏导致apikey被获取到盗用

2. ESM import 是提升执行的，dotenv 为什么必须在第一行
   因为环境必须优先加载 否则在模型初始化时报错

3. SSE 是什么，和 WebSocket 的区别
   sse是后端向前端进行实时通信的一种方式 他是单向的文本传输长链接 自动重连

4. 前端为什么用 while + read() 读流
   因为不加的话读取是一次性的

5. XSS 与 DOMPurify 的作用
   xss是脚本注入 dompirify通过对dom清洗 让v-html安全的渲染
